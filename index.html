PCでの使い方

  1. ブックマークバーを表示します（Chrome / Edge は Ctrl+Shift+B、Mac は ⌘+Shift+B）。
  2. 下の「TT Multi」ボタンをブックマークバーへドラッグして登録します（クリックでは登録されません）。
  3. TikTokの動画一覧が出るページ（プロフィール、検索結果、ハッシュタグなど）で、登録したブックマークをクリックします。
  4. サムネイル左上のチェックで動画を最大16本選び、右下の「Multi Playerで開く」を押すと、新しいタブでプレーヤーが開きます。
  5. パネルの「順に自動再生」を押すと、YouTubeショートのように1画面で動画を順に再生します。動画を選んでいればその動画を、選んでいなければそのページの動画を上から順に流します。
  6. 「Multi Playerで開く」で開いた画面でも、上部の「自動再生」をオンにすると、画面数より多く選んだ動画が、終わった画面に順に流れます（オフのときは同じ動画を繰り返します）。
  7. 選択はブックマークをクリックするたびと、プレーヤーを開いた後にクリアされます。動画は1つのページの中で選んでください。動画を開いているときは「この動画を追加」も使えます。

スマホでの使い方

  1. 下の「コードをコピー」を押します。
  2. このページをブックマークに追加し、そのブックマークを編集します。名前を「TT Multi」に、URLをコピーしたコードに置き換えて保存します。
  3. ブラウザーでTikTokの動画一覧が出るページ（プロフィール、検索結果など）を開き、ブックマークを実行します。TikTokアプリではなく、ブラウザーで開いてください。
    • Android（Chrome）: アドレスバーに「TT Multi」と入力し、候補に出たブックマークをタップします。
    • iPhone（Safari）: ブックマーク一覧を開き、「TT Multi」をタップします。
  4. サムネイル左上のチェックで動画を選び、「Multi Playerで開く」を押します。

再生できない動画

  • TikTok公式の埋め込みプレーヤーで再生するため、公開されていて埋め込みが許可された動画だけが再生できます。非公開・友達限定・年齢確認が必要な動画や、投稿者が埋め込みを止めた動画は再生できません。
  • 音量は変えられないため、↑ / ↓ キーは音声のオン / オフになります。倍速（G / H）は早送りを細かく繰り返して再現しているため、映像が少しカクつきます。
